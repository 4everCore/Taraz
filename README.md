# میزان | Mizan

A personal finance management web application built with Next.js, TypeScript, PostgreSQL, and Drizzle ORM.

## Features

- Personal income and expense management
- Financial accounts and transaction tracking
- Budget planning
- Debt management
- Savings goals
- Recurring transactions
- Financial reports
- Authentication
- Persian-friendly interface

## Tech Stack

- Next.js
- React
- TypeScript
- PostgreSQL
- Drizzle ORM
- Tailwind CSS
- Recharts

## Getting Started

### Requirements

- Node.js
- npm
- PostgreSQL

## راه‌اندازی پروژه

### . دریافت پروژه

مخزن پروژه را از گیت‌هاب دریافت کنید و وارد پوشه آن شوید.

### . نصب وابستگی‌ها

```bash
npm install
```

### . تنظیم متغیرهای محیطی

در مسیر اصلی پروژه، فایلی با نام `.env.local` ایجاد کنید و متغیرهای موردنیاز را در آن قرار دهید.

متغیرهای اصلی:

- `DATABASE_URL`: آدرس اتصال به پایگاه داده
- `AUTH_SECRET`: کلید محرمانه احراز هویت

مقادیر واقعی و محرمانه را در گیت‌هاب منتشر نکنید.

### . اجرای محیط توسعه

```bash
npm run dev
```

سپس نشانی زیر را در مرورگر باز کنید:

http://localhost:3000

## دستورهای کاربردی

| دستور | کاربرد |
|---|---|
| `npm run dev` | اجرای محیط توسعه |
| `npm run build` | ساخت نسخه آماده انتشار |
| `npm run start` | اجرای نسخه ساخته‌شده |
| `npm run lint` | بررسی قواعد کدنویسی |
| `npm run typecheck` | بررسی نوع‌های TypeScript |

## امنیت

- فایل `.env.local` نباید وارد مخزن گیت شود.
- برای محیط عملیاتی از کلیدهای محرمانه قوی و منحصربه‌فرد استفاده کنید.
- دسترسی‌های پایگاه داده را به‌درستی تنظیم کنید.
- پیش از انتشار عمومی، تنظیمات امنیتی و احراز هویت را بررسی کنید.
